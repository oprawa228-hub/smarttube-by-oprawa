# SmartTube by Oprawa

Тестовая версия клиента YouTube для Android TV: минималистичный интерфейс, наглядные настройки и управление пультом на основе [SmartTube](https://github.com/yuliskov/SmartTube).

[Скачать актуальный выпуск](https://github.com/oprawa228-hub/smarttube-by-oprawa/releases/latest)

## Установка и обновления

Выберите universal APK, если архитектура телевизора неизвестна. Установите поверх предыдущей SmartTube by Oprawa, сохраняя приложение и его данные. Официальный SmartTube устанавливается отдельно и удалять его не требуется.

Начиная с 32.70-oprawa.3 подключён собственный канал обновлений: «Настройки → Дополнительно → О приложении и обновления». Этот первый APK с каналом потребуется перенести вручную. Последующие выпуски приложение получает само; Android запрашивает подтверждение установки.

Приложение — тестовая модификация. Возможности конкретного телевизора проверяются отдельно. О найденных ошибках можно сообщать в Issues, указав версию приложения, модель ТВ, действия и ожидаемый результат.

## Исходники

Каждый выпуск содержит `smarttube-oprawa.patch`, `SOURCE.md`, контрольные суммы и лицензии. Patch применяется к указанной базовой ревизии оригинального SmartTube с зафиксированными подмодулями. Порядок восстановления и сборки — в `SOURCE.md` соответствующего релиза. Это репозиторий канала выпуска; полные изменения исходников доступны в артефактах релиза.
